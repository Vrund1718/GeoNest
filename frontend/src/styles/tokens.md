# GeoNest Design Tokens

## Colors
- chai-cup: #A67B5B → Warm accent for primary actions
- street-light: #F5D27E → Soft highlight for badges/hover
- monsoon-sky: #5A889C → Calm secondary accent
- kolkata-grey: #F0F0F0 → Neutral background
- ink-black: #2D2D2D → Primary text

## Typography
- Display: Poppins (bold for headings, medium for subheadings)
- Body: Noto Sans Devanagari + Roboto (regular/medium for body text)

## Layout
- Auth screens: Card-based on a soft kolkata-grey background with a subtle chai-cup divider at the top
- Dashboard: Clean split (sidebar + content area) with minimalist styling

## Signature Element
- Top border accent: A thin chai-cup line at the top of all primary cards/sections
